==== Configuration ====

Bot configuration can be reloaded at runtime. Anything described here can be easily changed. Currently describes only global bot configuration. Most modules have additional configuration settings available

=== Prefixes ===

Command prefixes are characters or words the bot will expect the active commands on the beginning of the line. Configured prefixes are:

{%- for prefix in cfg.prefixes() -%}
{{ "  * " }}''{{ prefix }}''

{%- endfor -%}
