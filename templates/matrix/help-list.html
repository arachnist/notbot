==== Prefixes ====

Command prefixes are characters or words the bot will expect the active commands on the beginning of the line. Configured prefixes are:

{%- for prefix in cfg.prefixes() -%}
{{ "  * " }}''{{ prefix }}''

{%- endfor -%}

{%- if set Some(restricted) = cfg.prefixes_restricted() -%}
There are also some restricted prefixes configred, that are to be used when the bot is directly replacing a functionality of another bot, that is still present on shared channels. These prefixes will only work with certain modules:

{%- for (prefix, mod_names) in restricted -%}
{{ "  * " }}''{{ prefix }}'' - modules: {%- for mod_n in mod_names -%}{{ " " }}{{ mod_n }}{%- endfor -%}

{%- endfor -%}
{%- endif -%}
{%- endif -%}


==== Active modules ====

Modules that will - per convention - actively respond to and "consume" specific events, usually prefixed keywords:

{%- for module in mods -%}
{{ "  * " }}''{{ module.name }}'': {{ module.help }}
{%- if set TriggerType::Keyword(v) = module.trigger -%}
; keyword{{ v.len() | pluralize }}:{% for kw in v %} ''{{ kw }}''{%- endfor -%}
{%- endif -%}


{%- endfor -%}


==== Passthrough modules ====

Modules that will only consume events if none of the "active" modules consumed an event in an "exclusive" manner:

{%- for module in pmods -%}
{{ "  * " }}''{{ module.name }}'': {{ module.help }}

{%- endfor -%}


==== Workers ====

A special type of module that will usually not respond directly to any Matrix event, and instead will act on some external events, eg. expose a web interface, or periodically monitor responses of some external APIs:

{%- for module in workers -%}
{{ "  * " }}''{{ module.name }}'': {{ module.help }}

{%- endfor -%}
{%- endblock -%}
